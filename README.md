# render-graph

## 题面

把渲染改成图驱动后，偶尔整帧黑屏、显存还越用越多：拓扑排序按注册顺序执行，依赖倒置时读到的资源还没写；不检测环，递归求值爆栈；别名只按资源大小配对，生命周期重叠的 RT 被复用导致串帧；屏障只插在格式变化处，同格式读写漏屏障；内存估算把别名资源重复计入，预算虚高；裁剪按 pass 是否被直接引用，间接触达的 pass 被误删；合并判断不考虑读写集合，合并后少一次写；未声明资源只在执行时才报错，校验阶段静默通过；同层 pass 排序依赖 dict 迭代顺序，两次执行顺序不同；批量执行遇非法图只跳过，输出里留下部分结果。rendergraph/graph.py 是核心，tests/test_graph.py 15个红。要修的是：按读写依赖稳定拓扑排序、检测环并抛 GraphError、生命周期安全别名、同格式读写屏障、别名去重内存估算、反向可达裁剪、读写感知合并、校验未声明资源、稳定同层排序、批量执行原子回滚。

## 运行方式

在仓库根目录执行：

```bash
python -m pytest tests -q
```

初始状态应恰好为 `15 failed`。不应出现 collection error、import error 或 syntax error；15 个测试都会在调用桩函数时因 `NotImplementedError` 失败。

## 约束

- 只使用 Python 标准库（`collections`、`heapq`）与 `pytest`；离线、无随机。
- `tests/` 不可修改；不要通过改测试、加同名测试或放宽断言来规避问题。
- 实现 `rendergraph/graph.py` 中的 8 个函数，保留公开签名与 `GraphError` 契约。
